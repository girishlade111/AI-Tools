# AI Tools Guide 2025

A comprehensive single-page guide to free and freemium AI tools in 2025 — browse
tools by category, compare free tiers, and learn strategies to pick the right
tool for your workflow.

## Features

- Curated directory of free and freemium AI tools across categories (chat,
  image, video, audio, productivity, and more)
- Interactive charts (Chart.js) showing tool trends and comparisons
- Strategy guides: how to evaluate, combine, and save money with free tiers
- Future-trends overview of where AI tooling is headed
- Fully responsive, mobile-friendly layout

## Tech Stack

- Plain HTML5 + CSS (Tailwind CSS via CDN)
- Vanilla JavaScript
- Chart.js for interactive charts
- Google Fonts (Inter)

## Quick Start

No build step — just open `index.html` in a browser:

```bash
# from the repo root
python3 -m http.server 8000
# then open http://localhost:8000
```

Or double-click `index.html` directly.

## Project Structure

```
AI-Tools/
├── index.html   # the entire site (markup, styles, scripts)
└── README.md
```

## Deploy Notes

- Static site — deploy anywhere that serves static files
  (GitHub Pages, Cloudflare Pages, Netlify, Vercel).
- All third-party dependencies are loaded via CDN, so no `npm install` needed.
